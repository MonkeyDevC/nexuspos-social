# NexusPOS · Contenido para redes

Material y calendario de publicaciones de @nexuspos.com.co.

## Estructura

```
posts/
  AAAA-MM-DD_tipo_tema/      una carpeta por publicación
    post.json                tipo, título, caption, imágenes/video y estado
    01.jpg, 02.jpg, ...      carrusel/imagen: JPEG 4:5 (896x1120), máx. 8 MB
```

Tipos: `carousel`, `image`, `reel`, `story`.
Estados: `draft` → `scheduled` → `published`.

Convención de nombres: fecha de publicación + tipo + tema en minúsculas con guiones.
